Responsive Design Principles

Fluid Layouts

Use flexible widths so page sections adapt smoothly across devices.

.container {
  width: 100%;
  max-width: 1200px;
}

Flexible Media

Images and video should resize proportionally to fit their containers.

img {
  max-width: 100%;
  height: auto;
}

Breakpoints

Apply media queries to adjust layout and spacing at key screen sizes.

@media (max-width: 600px) {
  .grid { grid-template-columns: 1fr; }
}
